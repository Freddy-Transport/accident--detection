# 0831 交通事故检测可视化测试报告

## 1. 测试目标

本次只进行模型测试和结果可视化，不进行任何训练。使用全量 ACCIDENT 数据微调得到的
VideoMAE checkpoint 对一个真实测试事故片段和一个 CARLA 虚拟事故视频进行片段级二分类，
并为汇报视频逐帧叠加事故车辆证据框。

## 2. 环境与模型

- 项目根目录：`/root/autodl-tmp/traffic_accident_rnd`
- VideoMAE：`best_acc_top1_epoch_2.pth`
- 事故阈值：`0.56`
- YOLO：`车辆检测_v8l.pt`，仅用于真实视频车辆检测
- Tracker：StrongSORT，仅用于真实视频轨迹关联
- 当前计算设备：CPU。实例未挂载 GPU，`nvidia-smi` 不可用
- 训练：未执行

## 3. 测试样本与结果

| 域 | 视频 | 事故类型 | 帧数 | 事故概率 | 判定 |
| --- | --- | --- | ---: | ---: | --- |
| 真实 CCTV | `-6SQSDj8cYU_00__accident.mp4` | t-bone | 90 | 0.8416 | accident |
| CARLA 虚拟 | `Town06_sideswipe_clear_26.mp4` | sideswipe | 181 | 0.6173 | accident |

真实样本来自 ACCIDENT 官方 test split 的派生事故窗口。虚拟样本来自 ACCIDENT synthetic
数据中的 Town06 sideswipe 场景。两个样本均超过阈值 `0.56`。

| 域 | VideoMAE 单片段推理耗时 |
| --- | ---: |
| 真实 CCTV | 341.57 s |
| CARLA 虚拟 | 14.06 s |

本表只表示两个正样本 demo 检测成功，不代表完整测试集精度，也不能估计误报率。当前 CPU
推理耗时不代表 GPU 部署速度。

## 4. 事故车辆可视化

### 真实视频

- 对 90 帧逐帧运行 YOLO，并由 StrongSORT 输出 90 帧轨迹。
- 事故区域关联车辆 ID 为 `6`、`1`，原始框分别覆盖 62 帧和 31 帧。
- 展示视频对缺失帧采用相邻轨迹框插值或最近框补齐，红框覆盖 90/90 帧。
- 红框是与事故区域和时刻最相关的疑似事故车辆，不是框级事故真值。

### 虚拟视频

- CARLA 标注给出碰撞 actor ID `371`、`373`。
- 两个 actor 均具有 181/181 帧二维框，红框直接来自 CARLA 标注，无需插值。
- 虚拟视频红框属于碰撞 actor 真值证据。

VideoMAE 本身不产生车辆框。所有帧显示事故分数、阈值、事故类型、当前时间和事故时刻。

## 6. 结论与边界

当前 checkpoint 在本次真实事故和虚拟事故正样本上均输出超过阈值的事故概率，并形成逐帧
事故车辆证据可视化。该结论仅说明两个 demo 样本检测成功。正式验收仍需加入真实
non-accident 与 hard negative CCTV 视频，统一评估事故召回率和误报率。
